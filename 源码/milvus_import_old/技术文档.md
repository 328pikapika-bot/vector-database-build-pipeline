# Milvus 向量库同步项目技术文档

## 一、项目概述

本项目是一个基于 **Python + Milvus** 的向量数据库导入与检索系统，主要用于：
- **学术论文数据导入**：从 API 接口获取学术论文数据，生成向量后存储到 Milvus 向量数据库
- **标准/问答数据导入**：支持从 Excel 文件导入标准数据和问答对数据
- **智能检索服务**：提供基于关键词的知识图谱查询和标准检索功能

### 技术栈
- **向量数据库**：Milvus 2.x (pymilvus)
- **向量化模型**：SentenceTransformer (m3e-base, 768维) / Qwen3-Embedding-0.6B (2560维)
- **API 框架**：FastAPI + Uvicorn
- **数据处理**：pandas, XML 解析, 正则表达式
- **异步处理**：多线程 (threading), 队列 (queue)
- **机器学习**：PyTorch, transformers

## 三、功能模块分析

### 3.1 论文数据导入模块

#### 3.1.1 英文论文导入 (`import_process.py`)

**功能逻辑**：
1. **数据获取** (`get_datas_api`):
   - 通过 HTTP GET 请求从 API 获取论文数据
   - 使用游标 (`cursor`) 实现分页，每批 25 条
   - 查询条件：包含 SCIE、SCOPUS、EI、SSCI、ESCI 收录级别或开放获取
   - 数据格式：XML 格式返回，解析后提取字段

2. **数据解析** (`parse_xml`):
   - 解析 XML 响应，提取论文元数据
   - 处理嵌套字段：作者、来源、文件、机构等
   - 数据清洗：空值填充默认值

3. **向量化** (`text2vec`):
   - 使用 `sentence-transformers/m3e-base` 模型
   - 批次大小：50 条
   - 向量维度：768 维
   - GPU 加速 (CUDA)

4. **数据入库** (`process_insert`):
   - 生产者-消费者模式：多线程处理
   - 队列缓冲：100万条数据队列
   - 批次插入：每 1000 条批量插入

**关键配置**：
```python
MILVUS_DB = {
    "host": "127.0.0.1",
    "port": "19530",
    "db_name": "nstl_db"
}

COLLECTION_INFO = {
    "name": "nstl_paper_abstract_ec_expand",
    "fields": [...],  # 24个字段，包含768维向量字段
    "index_params": {
        "metric_type": "IP",      # 内积相似度
        "index_type": "IVF_FLAT", # 倒排文件索引
        "nlist": 1024             # 聚类中心数
    }
}
```

#### 3.1.2 中文论文导入 (`import_list_process.py`)

**与英文导入的区别**：
- 使用期刊列表 (`journals.txt`) 作为查询条件
- 按期刊名称逐个查询，每期刊批量处理
- 使用 `cursor_log.text` 文件记录游标位置，支持断点续传
- 批次大小：50 条

### 3.2 标准数据导入模块 (`import_bz_process.py`)

**功能逻辑**：
1. **Excel 读取**：使用 pandas 读取标准融合表

### 3.3 问答数据导入模块 (`import_qa_process.py`)

**功能逻辑**：
1. **Excel 读取**：读取 `参考咨询.xlsx`
2. **向量化服务**：
   - 使用 VLLM 部署的 Qwen3-Embedding-0.6B 模型
   - API 调用：`http://127.0.0.1:8080/v1/embeddings`
   - 向量维度：2560 维
3. **数据格式**：
   - id, question, answer, class_name
   - question 字段向量化存储

**配置特点**：
- 使用 L2 距离度量（欧几里得距离）

### 3.4 检索服务模块 (`main_match.py`)

**FastAPI 服务**：

2. **知识图谱查询** (`query_neo4j`):
   - 多条件组合查询：前后属性匹配
   - 支持单关键词、双关键词组合查询
   - 返回关系路径文本

3. **标准检索** (`query_solr`):
   - 调用标准检索服务：`http://127.0.0.1:8001/search_standards`
   - POST 请求，返回标准 ID、名称、内容

### 4.2 性能与扩展性

#### 问题 4：单点瓶颈
**现状**：
- 向量化使用单 GPU (CUDA_VISIBLE_DEVICES="0")
- 数据获取和入库串行执行
- 无水平扩展能力

**影响**：
- 大规模数据处理（2600万条）耗时过长
- 无法利用多 GPU 加速

**建议**：
```python
# 1. 多 GPU 并行向量化
import torch
import torch.nn as nn
from multiprocessing import Pool

class MultiGPUEncoder:
    def __init__(self, model_path, num_gpus=None):
        self.num_gpus = num_gpus or torch.cuda.device_count()
        self.models = [
            SentenceTransformer(model_path).to(f'cuda:{i}')
            for i in range(self.num_gpus)
        ]
    
    def encode_parallel(self, texts, batch_size=64):
        # 将数据分片到多个 GPU
        chunks = np.array_split(texts, self.num_gpus)
        with Pool(self.num_gpus) as pool:
            results = pool.starmap(
                self._encode_chunk,
                [(chunk, i, batch_size) for i, chunk in enumerate(chunks)]
            )
        return np.concatenate(results)

# 2. 异步流水线
import asyncio
from asyncio import Queue

class AsyncPipeline:
    def __init__(self):
        self.fetch_queue = Queue(maxsize=1000)
        self.embed_queue = Queue(maxsize=1000)
        self.insert_queue = Queue(maxsize=1000)
    
    async def run(self):
        await asyncio.gather(
            self.fetch_worker(),
            self.embed_worker(),
            self.insert_worker()
        )
```

# 2. 批量处理 + 及时释放
class BatchProcessor:
    def __init__(self, batch_size=1000):

        if len(self.buffer) >= self.batch_size:

    def flush(self):

#### 问题 6：Milvus 索引配置不合理
**现状**：
```python
# IVF_FLAT 索引，nlist=1024
"index_params": {
    "metric_type": "IP",
    "index_type": "IVF_FLAT",
    "nlist": 1024
}
```

**问题**：
- IVF_FLAT 适合中等规模数据，但查询时需要扫描所有聚类中心
- nlist=1024 对于 2600万 数据可能不够（建议 nlist = 4 * sqrt(N) ≈ 20000）

**建议**：
```python
# 根据数据量动态选择索引
import math

def recommend_index_params(num_entities: int) -> dict:
    """根据数据量推荐索引参数"""
    if num_entities < 10000:
        # 小数据量：FLAT（精确搜索）
        return {
            "index_type": "FLAT",
            "metric_type": "IP"
        }
    elif num_entities < 1000000:
        # 中等数据量：IVF_FLAT
        nlist = min(4 * int(math.sqrt(num_entities)), 65536)
        return {
            "index_type": "IVF_FLAT",
            "metric_type": "IP",
            "params": {"nlist": nlist}
        }
    else:
        # 大数据量：HNSW（近似最近邻）
        return {
            "index_type": "HNSW",
            "metric_type": "IP",
            "params": {
                "M": 16,        # 每个节点的最大连接数
                "efConstruction": 200  # 构建时的搜索范围
            }
        }
```

#### 问题 9：断点续传不完善
**现状**：
- 使用 `cursor_log.text` 记录游标，但无状态持久化
- 程序中断后无法准确恢复进度
- 部分处理成功的数据可能重复插入

**建议**：
```python
import sqlite3
from dataclasses import dataclass
from datetime import datetime

@dataclass
class Checkpoint:
    cursor: str
    processed_count: int
    timestamp: datetime
    batch_id: str

class CheckpointManager:
    def __init__(self, db_path: str = "checkpoint.db"):
        self.conn = sqlite3.connect(db_path)
        self._init_table()
    
    def _init_table(self):
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS checkpoints (
                id INTEGER PRIMARY KEY,
                cursor TEXT,
                processed_count INTEGER,
                timestamp TEXT,
                batch_id TEXT,
                status TEXT
            )
        """)
    
    def save(self, checkpoint: Checkpoint):
        self.conn.execute("""
            INSERT INTO checkpoints (cursor, processed_count, timestamp, batch_id, status)
            VALUES (?, ?, ?, ?, 'in_progress')
        """, (checkpoint.cursor, checkpoint.processed_count, 
              checkpoint.timestamp.isoformat(), checkpoint.batch_id))
        self.conn.commit()
    
    def get_latest(self) -> Optional[Checkpoint]:
        cursor = self.conn.execute(
            "SELECT * FROM checkpoints ORDER BY timestamp DESC LIMIT 1"
        )
        row = cursor.fetchone()
        if row:
            return Checkpoint(
                cursor=row[1],
                processed_count=row[2],
                timestamp=datetime.fromisoformat(row[3]),
                batch_id=row[4]
            )
        return None
    
    def mark_completed(self, batch_id: str):
        self.conn.execute(
            "UPDATE checkpoints SET status = 'completed' WHERE batch_id = ?",
            (batch_id,)
        )
        self.conn.commit()
```
